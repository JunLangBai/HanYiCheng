## 🚀 Getting Started / 快速上手

To ensure the project runs smoothly without shader or script errors, please follow the installation steps strictly.

### 1️⃣ Environment Setup (Critical)
**Avoid Version Mismatch Errors!**
Before cloning the repo, you **must** download the specific Unity version recommended by the official Rokid documentation.

* 🔗 **Official Tutorial & Download:** [Rokid Unity Development Environment Setup](https://custom.rokid.com/prod/rokid_web/c88be4bcde4c42c0b8b53409e1fa1701/pc/cn/8ad2e74dbd7c4f5bb21a964dbdd5512d.html?documentId=f1ec651ab20a4eee9346857ef5129ec3)

### 2️⃣ Project Initialization
Once you have installed the correct Unity version:
1.  Open Unity Hub.
2.  Click **New Project**.
3.  **Important:** Select the **`3D Built-in Render Pipeline`** template.
    * *Do not select URP or HDRP as they may conflict with the current SDK materials.*

### 3️⃣ Build & Explore
After the project is created, follow the **"Quick Start"** section in the Rokid Documentation to configure your build settings.
